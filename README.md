# 🛢️ PetroSync — Projeto Integrador: Petróleo

> Projeto Integrador desenvolvido com foco no setor petrolífero, reunindo desenvolvimento de software e aplicação de conhecimentos técnicos para atender à proposta do projeto.

## 📌 Sobre o projeto

O **PetroSync** é um projeto desenvolvido no contexto da disciplina de Projeto Integrador, com temática voltada ao setor de petróleo.

O repositório reúne o código-fonte, a estrutura da solução e os arquivos necessários para o desenvolvimento e a evolução do sistema.

## 🎯 Objetivos

- Aplicar conhecimentos de desenvolvimento de software na construção de uma solução voltada ao setor petrolífero.
- Desenvolver uma aplicação organizada, sustentável e de fácil manutenção.
- Consolidar os conhecimentos adquiridos ao longo do curso por meio de um projeto prático.
- Utilizar boas práticas de programação e organização de código.

## 🛠️ Tecnologias utilizadas

- **C#** — linguagem de programação.
- **.NET** — plataforma de desenvolvimento.
- **Visual Studio / Visual Studio Code** — ambientes de desenvolvimento.
- **Git e GitHub** — versionamento e gerenciamento do código-fonte.

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de começar, você precisará ter instalado:

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Git](https://git-scm.com/)
- Um editor de código compatível com C#.

### 1. Clone o repositório

```bash
git clone https://github.com/brugnoloJoao/ProjetoIntegrador-Petroleo.git
```

### 2. Acesse o diretório

```bash
cd ProjetoIntegrador-Petroleo
```

### 3. Restaure as dependências

```bash
dotnet restore ProjetoIntegrador-Petroleo.slnx
```

### 4. Compile a solução

```bash
dotnet build ProjetoIntegrador-Petroleo.slnx
```

### 5. Execute a aplicação

Identifique o projeto executável dentro da pasta `ProjetoIntegrador-Petroleo` e execute:

```bash
dotnet run --project caminho/do/projeto.csproj
```
